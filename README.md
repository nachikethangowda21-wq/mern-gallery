# MERN Gallery

A full-stack gallery application built using React, Node.js,
Express.js and MongoDB.

## Features

- Create posts
- View gallery
- REST API
- MongoDB integration
- Responsive UI
- Full-stack deployment

## Tech Stack

Frontend:
- React
- Vite
- Axios
- CSS

Backend:
- Node.js
- Express.js
- MongoDB
- Mongoose
